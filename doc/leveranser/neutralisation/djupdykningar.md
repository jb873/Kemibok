## Varför den länkas från underdel C

Underdel C handlar om hur mycket som behövs, och stannar vid att det är antalet joner som avgör —
inte volymen. Djupdykningen tar vid precis där och visar hur man faktiskt räknar.

Fördjupningarna till underdel A, B och C pekar alla mot den, men kortet ligger i C eftersom det är
där frågan uppstår.

## Om kalkningen

Texten nämner att försurad mark och sjöar kan behandlas med kalk. Den användningen hör till
försurningsdelkapitlet.

**Låt meningen stå.** Djupdykningen är frivillig, meningen är kort, och försurningsdelkapitlet kan
bygga ut den. Eleven som läst djupdykningen känner igen sig när det kommer.
